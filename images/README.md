Drop your photos into the matching project folder using these exact file names
(format: **JPG**). Until a file exists, the page shows a neutral grey placeholder
box, so nothing breaks while you fill them in.

- `02.jpg` — vertical photo, **right** of the pair

- `04.jpg` — horizontal panorama (**bottom**)
